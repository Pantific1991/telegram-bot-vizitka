# Telegram-бот «Визитка»

Бот для малого бизнеса и частных специалистов: показывает меню с кнопками (услуги, цены, контакты) и принимает заявки от клиентов. Заявка сразу приходит владельцу в личные сообщения.

## Возможности
- Приветствие и меню с кнопками
- Разделы «Услуги», «Цены», «Контакты»
- Приём заявок: клиент описывает задачу, владелец получает сообщение с именем и текстом

## Как запустить
1. Установите Python 3.10 или новее
2. Установите библиотеку: `python -m pip install python-telegram-bot`
3. Создайте бота через @BotFather и вставьте токен в `bot.py` (переменная `TOKEN`)
4. Укажите свой Telegram Id в переменной `ADMIN_ID`
5. Запустите: `python bot.py`

## Что можно доработать под заказчика
- Свои тексты, цены и кнопки
- Сохранение заявок в Excel или Google Таблицу
- Запуск на сервере, чтобы бот работал круглосуточно
